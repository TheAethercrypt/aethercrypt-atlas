# ✦ The Aethercrypt: Atlas

### A Creative Cartography Studio for Worldbuilders

**Worlds forgotten. Stories eternal.**

The Aethercrypt: Atlas is an independent fantasy cartography studio created by **The Aethercrypt**. It was designed to give writers, worldbuilders, game creators, and fantasy enthusiasts a more approachable space to design and organize their fictional worlds.

From continents and kingdoms to rivers, settlements, borders, and trade routes, Atlas provides a collection of manual mapping tools to bring imaginary worlds to life.

---

## ✦ Features

### Map Creation & Drawing
- Draw continents, landmasses, islands, lakes, and rivers.
- Create borders, realms, coastlines, and trade routes.
- Add cities, villages, capitals, mountains, volcanoes, and custom pins.
- Use point-by-point or manual/freehand drawing methods.
- Customize map labels, colors, and text properties.

### Workspace & Editing
- Select, move, resize, rotate, and edit map objects.
- Add external images and adjust their size, opacity, and crop.
- Customize canvas dimensions and background appearance.
- Use grid and snapping options.
- Undo and redo editing actions.

### Layers & Organization
- Create and organize multiple layers.
- Reorder layers and adjust their opacity.
- Create layer groups.
- Organize pins into custom categories.
- Create linked submaps for individual regions.

### Cartographic Tools
- Place compass roses.
- Create custom map legends.
- Add private cartographer's notes.
- Use Timeline Mapper to preserve historical versions of your world.

### Export & Project Management
- Save projects as `.atlas.json` files.
- Reopen previously saved projects.
- Export finished maps as PNG images.
- Create and manage separate submaps.

### Extras
- Explore the built-in mini-game collection.
- Discover additional Aethercrypt projects through the project hub.
- Submit suggestions and report usability issues.

## ✦ Getting Started

The Aethercrypt: Atlas is a browser-based application.

You can use it directly through its hosted website or run it locally.

### Run Locally

1. Download or clone this repository.
2. Extract the project files if downloaded as a ZIP.
3. Open the project folder in Visual Studio Code or another code editor.
4. Open `index.html` in a modern web browser.

The project uses:

- `index.html` — Application structure.
- `styles.css` — Visual design and responsive layout.
- `script.js` — Application functionality.
- `favicon.svg` — Atlas icon.

No build process is required for the current version.

## ✦ Saving Your Projects

**IMPORTANT: PLEASE READ BEFORE USING ATLAS.**

The Aethercrypt: Atlas is an independent project currently provided as a beta.

Atlas does **not** upload or store your projects on The Aethercrypt website or on a cloud server. Your project files are stored locally only when you download them to your device.

### How to Save

1. Click **Save** in the top toolbar.
2. Read the beta save warning.
3. Select **I understand — Save project file**.
4. Keep the downloaded `.atlas.json` file somewhere safe.

### How to Open a Project

1. Open The Aethercrypt: Atlas.
2. Click **Open**.
3. Select your previously downloaded `.atlas.json` file.

### Backup Recommendations

- Keep at least two copies of important projects.
- Use a separate folder for your Atlas projects.
- Create new backups after important editing sessions.
- Use descriptive filenames and dates to identify versions.
- Consider keeping a backup on an external drive or trusted cloud storage service.
- Do not delete older versions until you have confirmed that your newest backup works.
